1. Define method to wrap supplied function,  
2. Register function's code object as target for tracing,  
3. Create a wrapper that executes function within context manager,  
4. Return wrapper that runs function and yields its result,  
5. Create a generator wrapper that manages generator execution within context,  
6. Initialize generator and set method to send values,  
7. Start infinite loop to drive generator,  
8. Within context, send incoming value to generator,  
9. On StopIteration, terminate wrapper,  
10. After generator step, yield its output and receive next input,  
11. If exception occurs during send, re-throw it into generator,  
12. Raise error if function is coroutine,  
13. Raise error if function is async generator,  
14. If function is a generator, return generator wrapper,  
15. Otherwise return simple wrapper.
